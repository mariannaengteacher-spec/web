# English Studio

Сайт репетитора английского языка и интерактивные учебники.

- `index.html` — главная страница сайта (с картинками `C.png` и `12.jpg`)
- `kursy.html` — страница «Курсы и материалы» со вкладками, слайдами и блокнотом (ссылка из меню главной)
- `coursebooks/` — страница «Студенты и учителя» (`coursebooks/index.html`) и интерактивные учебники

Сайт публикуется через GitHub Pages: Settings → Pages → Branch `main`, папка `/ (root)`.

Готовые ссылки на каждый учебник — в файле `LINKS.md`.

Старые адреса с русскими названиями (`1_Таблица.html`, `2_тренажер_слова.html`, `3_Курс_для_детей.html`, `6_Учебник.html`) оставлены как переадресации на новые.

В проекте два файла `index.html`, и так и должно быть: `index.html` в корне — главная страница сайта, `coursebooks/index.html` — страница учителя. У них разные адреса, они не мешают друг другу.
